# 08 · UI 约定与产品语义

> **改 UI 之前读这篇。** 这里记的是 master 明确定过 / 纠正过的行为约定，
> 以及那些"试过但被否掉"的设计 —— 避免你再提一次同样的方案。
>
> 坐标核算一律以 `lv_obj_align(..., LV_ALIGN_TOP_LEFT, x, y)` 计，屏幕 480×480。
> ⚠️ 本篇内容以**当前代码**为准核对过（`browser_screen.cpp` 的 `applyBarMode()` 等），
> 早期文档里关于底栏分组的描述已过时。

## 1. 产品语义（⛔ 这里改错过，别凭直觉）

| 控件 | 行为 |
|---|---|
| **三个点（⋯ / More）** | = **更多**。展开**组 A**：底部 URL 搜索框 + 刷新 + **退出浏览器** |
| 展开后的**左箭头（Back）** | 收回组 A，回到组 B 的导航键 |
| **首页（房子）** | 去**我们自己的搜索首页**（`showSearchHome()`）—— **不是**退出浏览器 |
| **下载** | 把当前页 HTML 存进 LittleFS（页面须还在 5 分钟缓存里，否则先刷新） |
| **退出浏览器** | 在组 A 里；也可以**左滑手势**退出 |

⛔ **踩过的错**：曾把三点键改成"回到搜索首页"，被 master 纠正。

> 三点 = 更多（搜索框 + 刷新 + 退出）；首页图标才管去搜索首页。
> **改任何一个 UI 语义前，先在屏幕上确认它现在是什么行为。**

| 区间 | 内容 |

## 3. 底部两组互斥工具栏

底栏只有一行（y=444，高 36），按钮比一行能容纳的多，所以分成两组切换：

- **组 B（默认显示）**：后退 / 前进 / 首页 / 刷新 / **下载**
- **组 A（三点展开）**：URL 搜索框 + 刷新 + **退出浏览器**

坐标（勿随意改，改了要重新核一遍是否重叠）：

```
组 A：URL 框 2–398（396 宽） | 刷新 | 退出
组 B：容器 g_navBar，五个按钮 @ 0 / 80 / 160 / 240 / 320
切换键固定占 x=404
```

### 实现约束

- 可见性**统一走 `applyBarMode()` 这一个出口**。`switch_bar_cb` 只翻转 `g_navModeB` 再调它。
  🚫 不要在各处手搓 `lv_obj_add_flag(..., LV_OBJ_FLAG_HIDDEN)` —— 两组一旦不同步就再也切不回来。
- 组 B 用**手工排布**而非 flex：等宽可控，切换键的位置才稳。
- 切换图标 **`icon_set_type()` 就地重画**同一块画布，不再 malloc（避免 PSRAM 碎片）。
- `g_status` **保留对象但加了 `LV_OBJ_FLAG_HIDDEN`**：`startFetch`/`tick`/`BrowserScreen_close`
  里有几十处 `lv_label_set_text(g_status, ...)`，隐藏后照常调用不影响逻辑。将来要恢复显示，删那一行即可。

### ⛔ 已否掉的设计：右下角圆形 FAB 菜单

曾实现 56px 圆形悬浮按钮 + 上方竖排菜单，**master 明确否掉** ——
他要的是底栏同配色按钮整体切换两组，不是浮在网页上的圆钮。
相关代码（`g_fab`/`g_fabMenu`/`makeMenuBtn`）已全部删除，**别再提这个方案**。

> 附带教训：编辑被中断（429）后留下过半状态 —— `g_navBar/g_switchBtn` 已声明却没创建，
> 而 FAB 的声明被删、代码还在引用 → 文件**编译不过**。

## 4. 状态栏

### 真实 FPS：只能从 `monitor_cb` 拿

早先用「`lv_timer_handler()` 被调用的次数」当帧数 —— 那只是主循环迭代次数
（`loop()` 里 `delay(5)`，跟屏幕刷新无关），会显示几百 fps 的虚高值。

LVGL 只在**真的重绘了脏区域之后**才调 `monitor_cb`（`lv_refr.c`：`if(disp_refr->inv_p != 0)`），
没重绘就不计数，所以画面静止时显示「静止」—— **那是对的**。

```cpp
lv_disp_t* disp = lv_disp_get_default();
if (disp && disp->driver && !disp->driver->monitor_cb)
    disp->driver->monitor_cb = monitor_cb;   // 每刷新一次 +1，同时累加渲染耗时
```

刷新周期受 `LV_DISP_DEF_REFR_PERIOD` 限制（默认 30ms）→ **真实 FPS 上限约 33**，
看到三位数一定是测错了地方。

### WiFi 图标：未点亮的格子用暗色，不要透明

`Icon::Wifi` 画 3 道弧 + 中心点，扇心 `0.70·S`、三弧 222°→318°。
`icon_create_wifi(parent, size, level)` 的 `level` 0..3 表示点亮几格，
**未点亮的格子用 `0x555555` 暗色画出来**，形状始终可见 —— master 明确要求**不要改成透明/无色**。

RSSI → 格数（`status_bar.cpp: rssiToLevel()`）：

| RSSI | 格数 |
|---|---|
| ≥ -55 | 3 |
| ≥ -67 | 2 |
| ≥ -78 | 1 |
| 其它 / 未连接 | 0 |

未连接也是 0 格（不再把整个图标压到 40% 不透明度 —— 那样弱信号时连格子都看不清）。

### 其它

- 时间 **12 小时制带 AM/PM**；`lv_font_montserrat_16` 是 ASCII-only，别往里塞汉字（会变豆腐块）。
- 蓝牙图标是 Feather 风格折线（占位，未接入）。
- 电池外框独立 2~3px（旧版 `S/16` = 1px 根本看不见）。

## 5. LVGL 对象约定

- `lv_obj_create(NULL)` 创建的屏幕**默认带 `LV_OBJ_FLAG_SCROLLABLE`**：
  手势检测前必须 `lv_obj_clear_flag(scr, LV_OBJ_FLAG_SCROLLABLE)`。
- 要接收触摸得显式 `lv_obj_add_flag(scr, LV_OBJ_FLAG_CLICKABLE)`。
- **默认事件和手势都不冒泡**：子对象会吞掉事件。
  需要冒泡的话加 `LV_OBJ_FLAG_EVENT_BUBBLE` / `LV_OBJ_FLAG_GESTURE_BUBBLE`。
- 🚫 别用 `lv_obj_remove_style_all()` —— 会触发
  `Cache disabled but cached memory region accessed`（见 [`09` 坑点速查表 C6](09-坑点速查表.md)）。
- Canvas 用 `LV_IMG_CF_TRUE_COLOR_ALPHA` 时每像素 **4 B**，`size*size*3` 会越界（同上 C7）。
- ⚠️ `lv_obj_get_scroll_bottom()` 在内容比容器矮时返回**负数**，不能当"内容总高"读。
  判断内容高度看日志里 `layout:` 那行的 `contentH=原始->缩放后`。
- ⚠️ 读 LVGL 尺寸前**必须先 `lv_obj_update_layout()`**，刚创建完拿到的坐标是陈旧的。
