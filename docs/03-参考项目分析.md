## 1. PyDOS-main

### 1.1 概述

PyDOS 是一个运行在 MicroPython/CircuitPython 上的 DOS 风格命令行 shell，支持 RP2040、ESP32、ESP32-S3 等多种微控制器板。它实现了 1981 年 IBM PC 级别的功能：命令行解释器、批处理文件、文件编辑器、BASIC 解释器等。

- 路径：`参考项目_unzipped\PyDOS-main\PyDOS-main\`
- 核心文件：`PyDOS.py`（1300 行，shell 主循环）、`boot.py`（启动配置）、`setup.bat`（板级适配）
- 支持板：RP2040, RP2350, ESP32, ESP32-S2/S3, nRF52840, SAMD51, Lilygo T-Deck, M5Stack Cardputer 等

### 1.2 含金量内容

#### (1) 多板适配模式

`setup.bat` 通过交互式提示让用户选择板型，然后拷贝对应平台的程序和库到 `/lib` 目录。`boot.py` 则根据 `implementation.name` 和 `board.board_id` 做运行时分支：

```python
# boot.py - 运行时板级检测
from sys import implementation
if implementation.name.upper() == "CIRCUITPYTHON":
    import board, digitalio, storage
    if board.board_id == 'arduino_nano_rp2040_connect':
        swpin = board.D2
    elif board.board_id in ['raspberry_pi_pico','cytron_maker_pi_rp2040']:
        swpin = board.GP6
    # ...
elif implementation.name.upper() == "MICROPYTHON":
    # MicroPython 分支
```

#### (2) 命令行 shell 架构

`PyDOS.py` 实现了完整的命令分发循环，支持环境变量（PATH、PROMPT、LIB、DIRSEP）、通配符匹配（`_match` 函数）、批处理执行（GOTO、IF、PAUSE、REM）、管道和重定向。命令分内置命令（DIR、CD、COPY、DEL 等）和外部程序（.py 文件）。

#### (3) 文件系统抽象

包含 `sdmount.py`/`sdumount.py`（SD 卡挂载）、`fileview.py`（文件查看）、`xcopy.py`（递归拷贝）、`edlin.py`（行编辑器）、`diff.py`（文件比较）。这些构成了完整的文件操作工具集。

### 1.3 相关性评估

**中等**。PyDOS 是 MicroPython 生态，本项目用 ESP-IDF C++。但其"命令行 shell"思路可借鉴：小手机系统中可实现一个 Terminal App，支持命令解析、文件浏览、系统配置。多板适配的"运行时检测 + 分支"模式也值得参考。

### 1.4 推荐复用

- 命令行解析思路（命令分发、参数解析、通配符）可用于实现 Terminal App
- 文件系统操作工具集的设计思路（mount/list/copy/diff）

## 2. MicroPythonOS-main

### 2.1 概述

MicroPythonOS 是一个基于 MicroPython + LVGL 的完整微控制器 GUI 操作系统，具有 Android 风格的 Activity/Intent 架构、应用管理、通知栏、手势导航等。这是本次分析中架构含金量最高的项目。

- 路径：`参考项目_unzipped\MicroPythonOS-main\MicroPythonOS-main\`
- 核心框架：`internal_filesystem/lib/mpos/`
- 构建基础：`lvgl_micropython`（LVGL 的 MicroPython 绑定）
- 文档极其详尽：`AGENTS.md`（22KB）记录了所有开发规则、陷阱、调试方法

### 2.2 含金量内容

#### (1) Activity / Intent 架构（极高含金量）

`activity_navigator.py` 实现了 Android 风格的 Activity 导航：

```python
# activity_navigator.py - Intent 驱动的 Activity 启动
class ActivityNavigator:
    @staticmethod
    def startActivity(intent):
        if intent.action:  # 隐式 Intent：解析处理器
            handlers = AppManager.resolve_activity(intent)
            if len(handlers) == 1:
                ActivityNavigator._dispatch(intent, handlers[0])
            else:
                ActivityNavigator._show_chooser(intent, handlers)  # 多处理器弹选择器
        else:
            ActivityNavigator._launch_activity(intent)  # 显式 Intent

    @staticmethod
    def _launch_activity(intent, result_callback=None):
        activity = intent.activity_class
        if callable(activity):
            activity = activity()       # 实例化
        activity.intent = intent
        activity.appFullName = intent.app_fullname
        mpos.ui.save_and_clear_current_focusgroup()
        activity.onCreate()             # 生命周期回调
```

#### (2) 屏幕栈与生命周期管理（极高含金量）

`view.py` 用 `screen_stack` 列表管理屏幕栈，完整实现 Activity 生命周期：

```python
# view.py - 屏幕栈管理
screen_stack = []  # [(activity, screen, focusgroup, focused_obj), ...]

def setContentView(new_activity, new_screen):
    if screen_stack:
        current_activity, current_screen, _, _ = screen_stack[-1]
        current_activity.onPause(current_screen)   # 暂停当前
        current_activity.onStop(current_screen)     # 停止当前
    screen_stack.append((new_activity, new_screen, lv.group_create(), None))
    new_activity.onStart(new_screen)                # 启动新屏幕
    # 滑动动画进入
    lv.screen_load_anim(new_screen, lv.SCREEN_LOAD_ANIM.OVER_LEFT, 500, 0, auto_del)
    new_activity.onResume(new_screen)               # 恢复新屏幕

def finish_current_activity():
    remove_and_stop_current_activity()              # onDestroy
    prev_activity, prev_screen, _, _ = screen_stack[-1]
    # 滑动动画返回
    lv.screen_load_anim(prev_screen, lv.SCREEN_LOAD_ANIM.OVER_RIGHT, 500, 0, True)
    prev_activity.onResume(prev_screen)
```

生命周期完整链路：`onCreate -> onStart -> onResume -> onPause -> onStop -> onDestroy`，加上 `onBackPressed` 返回键处理。

#### (3) SharedPreferences - JSON 明文存储（高含金量，符合本项目偏好）

`shared_preferences.py` 用 JSON 文件实现偏好存储，无服务器、明文、按应用隔离：

```python
# shared_preferences.py - JSON 文件存储
class SharedPreferences:
    def __init__(self, appname, filename="config.json", defaults=None):
        self.appdir = f"prefs/{self.appname}"
        self.filepath = f"{self.appdir}/{self.filename}"
        self.data = {}
        self.load()

    def _load_file(self, path):
        with open(path, 'r') as f:
            self.data = ujson.load(f)  # JSON 明文加载
```

存储结构：`prefs/<appname>/config.json`，每个应用独立目录，支持默认值、迁移、空目录清理。

#### (4) 手势导航（高含金量，符合本项目滑动交互需求）

`gesture_navigation.py` 实现边缘滑动返回、顶部下滑：

def _back_swipe_cb(event):
    point = lv.point_t()
    indev.get_point(point)
    x, y = point.x, point.y
    if event_code == lv.EVENT.PRESSED:
        back_start_x, back_start_y = x, y
    elif event_code == lv.EVENT.PRESSING:
        # 滑动超过阈值显示返回按钮
        should_show = not is_short_movement(dx, dy)

#### (5) WidgetAnimator - 滑动面板动画（高含金量）

`widget_animator.py` 的 `SlidePanel` 封装了垂直滑动动画，处理快速开合无故障：

```python
# widget_animator.py - 滑动面板
class SlidePanel:
    def __init__(self, widget, shown_y, hidden_y, duration=300, use_hidden_flag=True):
        self.shown_y = shown_y       # 显示位置
        self.hidden_y = hidden_y     # 隐藏位置（屏幕外）
        self.is_open = False

    def show(self, animate=True):
        if self.is_open: return
        self.is_open = True
        lv.anim_delete(self.widget, None)  # 取消进行中的动画
        self._animate(self.hidden_y, self.shown_y, self._on_show_done)
```

## 3. gfx_lib (Arduino_GFX 1.4.6)

### 3.1 概述

Arduino_GFX 是一个 Arduino 图形库，支持多种显示面板和数据总线接口，从 Adafruit_GFX、LovyanGFX、TFT_eSPI 等库重写而来。

- 路径：`参考项目_unzipped\gfx_lib\Arduino_GFX-1.4.6\`
- 核心目录：`src/display/`（40+ 显示驱动）、`src/databus/`（数据总线）、`src/font/`（字体）

### 3.2 含金量内容

#### (1) 显示驱动抽象层

`Arduino_GFX.h` 定义基类，`src/display/` 下每种面板一个驱动（ILI9341、ST7789、ST7796、RGB_Display 等）。注意：**没有 ST7701 驱动**，但有通用的 `Arduino_RGB_Display.h`（55KB）。

#### (2) U8g2 字体支持（Unicode/UTF8）

支持 U8g2 压缩字体，包括中文、日文、韩文：

```c
gfx->setUTF8Print(true);
gfx->setFont(u8g2_font_unifont_t_chinese2);
gfx->println("世界你好!");
```

#### (3) 数据总线抽象

`Arduino_DataBus.h` 抽象了 SPI、I2C、8位/16位并口等总线。

### 3.3 相关性评估

**低**。本项目使用 ESP-IDF 的 `esp_lcd_st7701` 组件驱动显示，不需要 Arduino_GFX 的驱动层。Arduino 框架也与本项目的 ESP-IDF 原生框架不兼容。

### 3.4 推荐复用

- U8g2 字体的 Unicode/中文字体思路可参考（但 LVGL 自带字体工具更合适）

## 5. ESP32-4848S040-First-Start-main

### 5.1 概述

这是与本项目硬件完全一致的现成 BSP（板级支持包）。使用 ESP-IDF 原生框架 + LVGL 9，驱动 ST7701S RGB 显示 + GT911 触摸。

- 路径：`参考项目_unzipped\ESP32-4848S040-First-Start-main\ESP32-4848S040-First-Start-main\`
- 硬件：ESP32-S3-WROOM-1U-N16R8（16MB Flash, 8MB PSRAM）、4.0" 480x480 RGB565、ST7701S、GT911
- 框架：ESP-IDF v5.5 + PlatformIO + LVGL 9.x
- **注意**：此项目用 LVGL 9，本项目用 LVGL 8.3，API 有差异需适配

### 5.2 含金量内容

#### (1) board_config.h - 完整引脚定义（直接可用）

```c
// src/board_config.h - 硬件引脚（与本项目完全一致）
#define LCD_H_RES               480
#define LCD_V_RES               480
#define LCD_BIT_PER_PIXEL       16

// RGB 数据线 R0-R4, G0-G5, B0-B4
#define LCD_RGB_R0  11  // ... R4=0
#define LCD_RGB_G0  8   // ... G5=10
#define LCD_RGB_B0  4   // ... B4=15
#define LCD_RGB_DE  18
#define LCD_RGB_VSYNC 17
#define LCD_RGB_HSYNC 16
#define LCD_RGB_PCLK 21

// 3-wire SPI (ST7701S 初始化)
#define LCD_SPI_CS  39
#define LCD_SPI_SCK 48
#define LCD_SPI_SDA 47

// GT911 触摸 I2C
#define TOUCH_I2C_SDA 19
#define TOUCH_I2C_SCL 45
#define TOUCH_I2C_CLK_HZ (400 * 1000)

// 背光 PWM
#define LCD_BL_GPIO 38
```

关键时序经验：**HBP=HFP=VBP=VFP=0 是唯一稳定配置**，非零值会在约 100 个周期后产生漂移。PCLK 由行时间 32us 推导（`LCD_USE_LINE_TIME_PCLK=1`）。

#### (2) display.c - ST7701S 初始化序列（直接可用）

包含完整的 ST7701S 初始化命令序列（Gamma、Power、GIP 设置），基于厂家 datasheet：

```c
// src/display.c - ST7701S init commands
static const st7701_lcd_init_cmd_t st7701_init_cmds[] = {
    {0xFF, (uint8_t []){0x77, 0x01, 0x00, 0x00, 0x13}, 5, 0},  // 页选择
    {0xC0, (uint8_t []){0x3B, 0x00}, 2, 0},       // LNESET
    {0xC1, (uint8_t []){0x0D, 0x02}, 2, 0},       // PORCTRL
    {0xB0, (uint8_t []){0x00, 0x11, 0x18, ...}, 16, 0},  // Gamma正
    {0xB1, (uint8_t []){0x00, 0x11, 0x19, ...}, 16, 0},  // Gamma负
    // ... Power, GIP 设置
    {0x11, (uint8_t []){0x00}, 0, 120},  // Sleep out (120ms)
    {0x29, (uint8_t []){0x00}, 0, 20},   // Display on
};
```

RGB panel 配置使用 PSRAM framebuffer（`fb_in_psram=true`）、单 framebuffer、无 bounce buffer。

#### (3) touch.c - GT911 驱动（直接可用，含鲁棒处理）

```c
// src/touch.c - GT911 I2C 地址自动探测 + 坐标缩放
esp_err_t touch_init(esp_lcd_touch_handle_t *touch_handle) {
    // 尝试主地址，失败则尝试备用地址
    uint8_t gt911_addr = ESP_LCD_TOUCH_IO_I2C_GT911_ADDRESS;
    ret = gt911_read_reg(gt911_addr, GT911_REG_SWITCHES, &switches, 1);
    if (ret != ESP_OK) {
        gt911_addr = ESP_LCD_TOUCH_IO_I2C_GT911_ADDRESS_BACKUP;  // 0x5D vs 0x14
        ret = gt911_read_reg(gt911_addr, ...);
    }
    // 读取 GT911 原始最大 X/Y，缩放到显示分辨率
    gt911_read_reg(gt911_addr, GT911_REG_MAX_VALUES, max_xy, 4);
    s_gt911_x_raw_max = (max_xy[1] << 8) | max_xy[0];
    // process_coordinates 回调做缩放
}
```

### 5.3 LVGL 9 vs 8.3 API 差异适配

此项目用 LVGL 9，本项目用 LVGL 8.3，主要 API 差异：

| LVGL 9 (此项目) | LVGL 8.3 (本项目) | 说明 |
|------------------|-------------------|------|
| `lv_display_t` / `lv_display_create()` | `lv_disp_t` / `lv_disp_create()` | 显示对象 |
| `lv_screen_load()` / `lv_screen_active()` | `lv_scr_load()` / `lv_scr_act()` | 屏幕加载 |
| `lv_display_set_flush_cb()` | `lv_disp_set_flush_cb()` | flush 回调 |
| `lv_display_set_buffers()` | `lv_disp_set_draw_buffers()` | 绘制缓冲 |
| `LV_DISPLAY_RENDER_MODE_PARTIAL` | `LV_DISP_RENDER_MODE_PARTIAL` | 渲染模式 |
| `lv_indev_create()` + `lv_indev_set_type()` | `lv_indev_create()` 直接传类型 | 输入设备 |
| `lv_event_get_target_obj()` | `lv_event_get_target()` | 事件目标 |
| `lv_button` / `lv_image` | `lv_btn` / `lv_img` | 控件命名 |

### 5.4 相关性评估

**极高**。这是本项目硬件的现成 BSP，引脚定义、ST7701S 初始化序列、GT911 驱动、背光控制、LVGL 集成模式均可直接复用。仅需将 LVGL 9 API 适配为 8.3。

| 内容 | 复用方式 | 优先级 |

### 7.1 概述

- 硬件：ESP32-S3-BOX（与本项目的 4848S040 板不同）
- 框架：ESP-IDF C++ + LVGL

### 7.2 含金量内容

#### (1) LVGL C++ 封装模式（高含金量）

`gui.hpp` 展示了良好的 LVGL C++ 封装：单例、互斥锁、定时器任务、事件订阅：

```cpp
// components/gui/include/gui.hpp
class Gui {
public:
  struct Config {
    play_haptic_fn play_haptic;       // std::function 回调注入
    set_waveform_fn set_waveform;
    std::string metadata_filename = "metadata.csv";
  };
  explicit Gui(const Config& config) {
    init_ui();
    task_.periodic(16 * 1000);        // 60fps GUI 更新任务
    // 事件订阅模式
    espp::EventManager::get().add_subscriber(battery_topic, "gui",
      std::bind(&Gui::on_battery, this, _1), 5*1024);
  }
  // 统一事件回调分发
  static void event_callback(lv_event_t *e) {
    auto gui = static_cast<Gui*>(lv_event_get_user_data(e));
    switch (lv_event_get_code(e)) {
      case LV_EVENT_PRESSED: gui->on_pressed(e); break;
      case LV_EVENT_VALUE_CHANGED: gui->on_value_changed(e); break;
      case LV_EVENT_KEY: gui->on_key(e); break;
    }
  }
protected:
  std::recursive_mutex &mutex_{BoxEmu::lvgl_mutex()};  // 共享 LVGL 互斥锁
};
```

#### (2) BSP 单例抽象（高含金量）

lv_image_dsc_t make_boxart(const std::string& path) {
  decoder_.decode(path.c_str());
  lv_image_dsc_t img_desc;
  img_desc.header.cf = LV_COLOR_FORMAT_NATIVE;
  img_desc.header.w = decoder_.get_width();
