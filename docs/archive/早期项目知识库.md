# 当前项目知识库

## 1. 硬件平台

### 1.1 核心规格
- **MCU**: ESP32-S3 Xtensa LX7 双核 240MHz
- **Flash**: 16MB Quad SPI（必须 DIO 模式，QIO 会 boot loop）
- **PSRAM**: 8MB OPI（必须 `qio_opi`，`opi_opi` 会 abort: EFUSE 未配 octal）
- **RAM**: 320KB SRAM + 8MB PSRAM

### 1.2 显示屏
- **型号**: ST7701S 4.0inch RGB IPS
- **分辨率**: 480×480
- **接口**: 16bit RGB 并行（DE 模式）
- **PCLK**: **10MHz**（降到 10MHz 给 PSRAM 留带宽，16MHz 会花屏）
- **背光**: GPIO38 PWM 可调

### 1.3 触摸
- **型号**: GT911 电容触摸
- **接口**: I2C（SDA=GPIO19, SCL=GPIO45）
- **INT/RST**: 均为 -1（板子未接），只能 I2C 轮询，不能用中断唤醒
- **去抖**: 10ms 窗口复用上次结果，避免 I2C 中断风暴挤占 PSRAM 带宽

### 1.4 引脚定义（pins.h）
```
背光: 38  CS: 39  SCK: 48  SDA: 47
DE: 18  VSYNC: 17  HSYNC: 16  PCLK: 21
R[0-4]: 11,12,13,14,0
G[0-5]: 8,20,3,46,9,10
B[0-4]: 4,5,6,7,15
触摸 SDA: 19  SCL: 45  INT: -1  RST: -1
```

- **LVGL**: 8.3.0-dev（厂商库，路径 `Libraries/Lvgl/`）

### 2.2 关键 build_flags
```ini
-DBOARD_HAS_PSRAM
-DCONFIG_SPIRAM_USE_MALLOC=1
-DCONFIG_SPIRAM_TRY_ALLOCATE_WIFI_LWIP=1
-DLV_COLOR_16_SWAP=0
-DLV_LVGL_H_INCLUDE_SIMPLE    # 字体文件 include "lvgl.h" 而非 "lvgl/lvgl.h"
-D_GNU_SOURCE
```

### 2.3 关键配置
- `lib_ignore = Time` — Time 库会遮蔽 newlib `<time.h>`，导致 NTP/时区失败
- `board_build.flash_mode = dio` — 必须 DIO，QIO bootloader 卡死
- `board_build.arduino.memory_type = qio_opi` — Flash QIO + PSRAM OPI
- `build_dir = .wb_build` — 不要删 `.pio` 目录（会触发宿主 safe-delete 拦截）

### 4.2 屏幕导航
- `nav_launcher` / `nav_clock` / `nav_settings` 全局指针
- `nav_go(scr)` — 即时切换
- `nav_go_anim(scr, anim, time, auto_del)` — 动画切换
- 动画类型: `LV_SCR_LOAD_ANIM_MOVE_LEFT/RIGHT/TOP/BOTTOM`, `OVER_LEFT/RIGHT`

### 4.3 手势/滑动检测
**不用 `LV_EVENT_GESTURE`**（LVGL 内部手势检测阈值 50px+3px/帧，且子对象没设 `GESTURE_BUBBLE` 会吞掉）

改用 **`LV_EVENT_PRESSED` + `LV_EVENT_PRESSING` + `LV_EVENT_RELEASED`** 手动检测：
```cpp
// nav.h 中的 swipe_detect()
// PRESSED: 记录起点
// PRESSING: 位移 >40px 触发导航
// RELEASED: 重置 triggered flag
```

子对象（back 按钮、校准按钮）加 `LV_OBJ_FLAG_EVENT_BUBBLE` 让 PRESSED/PRESSING 冒泡到 screen。


## 5. 已解决的坑

### 5.1 花屏（PCLK 16MHz → 10MHz）
**根因**: PSRAM 带宽争抢 — LCD DMA 恒定从 PSRAM 抽像素流，CPU 并发写 PSRAM 时 DMA 饿死几拍 → 刷新瞬间花屏。
**修复**: PCLK 10MHz + PSRAM 双缓冲 120 行 + 触摸 10ms 去抖

### 5.2 Boot loop（Flash QIO → DIO）
**根因**: QIO 模式 bootloader 卡死 → TG0WDT 复位
**修复**: `board_build.flash_mode = dio` + 烧录用 `esptool --flash-mode dio`

### 5.3 `lv_obj_remove_style_all` panic
**根因**: 触发 `Cache disabled but cached memory region accessed`
**修复**: 改用 `lv_obj_set_style_border_width(obj,0,0)` + `lv_obj_set_style_pad_all(obj,0,0)` + `lv_obj_set_style_bg_opa` + `lv_obj_clear_flag(LV_OBJ_FLAG_SCROLLABLE)`

### 5.4 Canvas 缓冲越界
**根因**: `LV_IMG_CF_TRUE_COLOR_ALPHA` 是 4B/px，`size*size*3` 会越界写产生白线
**修复**: 改为 `size*size*4`，从 PSRAM 分配（`heap_caps_malloc(MALLOC_CAP_SPIRAM)`）

### 5.5 中文字体编码损坏
**根因**: PowerShell 传 `--symbols` 时中文编码损坏，生成的字体全是西里尔字母
**修复**: 用 Python `subprocess` 调 `node lv_font_conv.js`，UTF-8 正确传递

### 5.6 GPIO 227 告警（无害）
**根因**: `TAMC_GT911::reset()` 对 INT/RST=-1 无守卫，-1 截断成 255，`digitalPinList[255]`=GPIO 227
**状态**: 触摸走 I2C 轮询正常，告警可忽略

## 6. 中文字体方案

### 6.1 生成方法
```bash
# 1. 用 Python 生成汉字表（UTF-8 无 BOM）
python tools/gen_symbols.py tools/zh_symbols_v2.txt

# 2. 用 node + lv_font_conv 转换
node lv_font_conv.js --font C:\Windows\Fonts\simhei.ttf \
  --size 16 --bpp 4 --format lvgl \
  -r 0x20-0x7E -r 0x3000-0x303F \
  --symbols <汉字> \
  --lv-font-name font_zh_16 --no-kerning \
  -o src/app/font_zh_16.c
```

### 6.2 字符集
- 373 个常用汉字（覆盖项目所有用字 + UI 通用字 + 高频日常字）
- ASCII 0x20-0x7E
- CJK 标点 0x3000-0x303F
- 字体: simhei.ttf（系统黑体）

### 6.3 使用
```cpp
#include "font_zh.h"
// font_zh_16: 16px（正文/提示/日期）
// font_zh_24: 24px（标题）
// 纯数字/英文仍用 montserrat
lv_obj_set_style_text_font(label, &font_zh_16, 0);
```

## 7. LVGL 注意事项

### 7.1 lv_conf.h 位置
厂商库目录的 `Libraries/Lvgl/lv_conf.h` 会覆盖 `src/config/lv_conf.h`，修改配置要改库目录的。

### 7.2 屏幕对象
- `lv_obj_create(NULL)` 创建屏幕，默认有 `LV_OBJ_FLAG_SCROLLABLE`
- 手势检测前必须 `lv_obj_clear_flag(scr, LV_OBJ_FLAG_SCROLLABLE)`
- 加 `lv_obj_add_flag(scr, LV_OBJ_FLAG_CLICKABLE)` 才能接收触摸

### 7.3 事件冒泡
- `LV_OBJ_FLAG_EVENT_BUBBLE` 控制事件是否冒泡到父对象
- `LV_OBJ_FLAG_GESTURE_BUBBLE` 控制手势事件是否冒泡
- 默认都不冒泡，子对象会吞掉事件

### 7.4 动画
- `lv_scr_load_anim(target, anim, time, delay, auto_del)`
- `auto_del=true` 动画后删除旧屏（欢迎页→launcher 用）
- `auto_del=false` 保留旧屏（clock↔launcher 往返用）
